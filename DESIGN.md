## Refero Inspirations

- Stripe: clean SaaS command center, white canvas, compact typography, strong structure, subtle elevation.
- Mintlify: precise information architecture, restrained grayscale, clear hierarchy, one functional accent.
- Limitless / Rox: architectural precision, muted surfaces, careful spacing, neutral-heavy UI with status accents.

## Product Fit

AutoNet is an administrative financial cockpit. It should feel calm, serious and operational:

- dense enough for repeated work
- reassuring without being playful
- status-driven rather than decorative
- clear tables and forms over marketing composition
- cautious warnings for legal/fiscal uncertainty

## Visual Tokens

- Ink: `#061b31`
- Muted text: `#50617a`
- Canvas: `#f8fafd`
- Soft band: `#eef4f8`
- Border: `#d8dfe8`
- Primary action: `#0c8c5e`
- Secondary action/accent: `#2f6fed`
- Warning: `#b76e00`

## Component Rules

- Cards: 6-8px radius, subtle border, soft shadow, compact padding.
- Buttons: 6px radius, clear icon+text when useful, no oversized pills in the app shell.
- Tables: quiet headers, strong row separation, numeric values easy to scan.
- Forms: labels above fields, explanatory help text only when it prevents mistakes.
- Status: color is reserved for actionable state, threshold risk and warnings.

## Landing

The landing can be more spacious than the app, but still product-first. It should show the cockpit and the core workflow immediately, not abstract decoration.
